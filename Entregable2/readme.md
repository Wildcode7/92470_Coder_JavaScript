# Pre-Entrega 2: Lógica de Programación y Control de Flujo

## Descripción

Este proyecto consiste en un simulador de compras desarrollado con HTML y JavaScript. Permite al usuario ingresar la cantidad de productos que desea comprar, validar la disponibilidad del inventario, calcular el valor de la compra y actualizar el stock restante.

## Funcionalidades

- Solicitud de la cantidad de productos mediante `prompt()`.
- Validación de cantidades mayores que cero.
- Comprobación de la disponibilidad del stock.
- Cálculo del total de la compra.
- Actualización del inventario después de una compra válida.
- Posibilidad de realizar varias compras mediante un ciclo `while`.
- Validación de la respuesta para continuar o finalizar.
- Mensajes informativos mediante `console.log()`, `alert()` y `confirm()`.

## Conceptos de JavaScript aplicados

- Variables con `let` y `const`.
- Tipos de datos y conversión numérica.
- Operadores aritméticos y de comparación.
- Estructuras condicionales `if`, `else if` y `else`.
- Ciclo `while`.
- Validación de entradas del usuario.
- Control del flujo del programa mediante variables booleanas.

## Estructura del proyecto

- `index.html`: estructura de la página y conexión con JavaScript.
- `js/main.js`: lógica del simulador de compras.

## Tecnologías
