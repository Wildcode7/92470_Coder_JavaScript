# Pre-Entrega 1: Primeros pasos con JavaScript

## Descripción

Este proyecto corresponde a mi primera actividad práctica del curso de JavaScript de Coderhouse. El ejercicio consiste en solicitar información al usuario, realizar un cálculo sencillo y mostrar un mensaje personalizado.

## Funcionalidades

- Solicitud del nombre mediante `prompt()`.
- Solicitud del año de nacimiento.
- Conversión del año ingresado a un número mediante `parseInt()`.
- Cálculo de la edad tomando como referencia el año 2026.
- Solicitud de la ciudad de residencia.
- Presentación del resultado mediante `console.log()` y `alert()`.

## Conceptos de JavaScript aplicados

- Declaración de variables con `let` y `const`.
- Entrada de datos mediante `prompt()`.
- Conversión de datos con `parseInt()`.
- Operaciones aritméticas.
- Concatenación de cadenas de texto.
- Salida de información con `console.log()` y `alert()`.

## Estructura del proyecto

- `index.html`: estructura de la página y conexión con JavaScript.
- `js/main.js`: código JavaScript que solicita los datos, calcula la edad y muestra el resultado.
