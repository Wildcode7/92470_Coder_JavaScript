# Pre-Entrega 3: Funciones e Integración de Lógica

## Descripción

Este proyecto consiste en un simulador de compras desarrollado con HTML y JavaScript. Permite solicitar una cantidad de productos, validar la compra según el inventario disponible, calcular el total a pagar y actualizar el stock.

## Funcionalidades

- Solicitud de cantidad mediante `prompt()`.
- Validación de cantidades enteras positivas.
- Comprobación del inventario disponible.
- Cálculo del total de la compra.
- Actualización del stock restante.
- Posibilidad de realizar varias compras mediante un ciclo `while`.
- Manejo de la cancelación de la entrada del usuario.
- Mensajes mediante `console.log()`, `alert()` y `confirm()`.

## Conceptos de JavaScript aplicados

- Funciones declaradas y función flecha.
- Parámetros y argumentos.
- Valores de retorno con `return`.
- Condicionales `if`, `else if` y `else`.
- Ciclo `while` y sentencia `break`.
- Variables con `const` y `let`.

## Estructura del proyecto

- `index.html`: estructura de la página y conexión con JavaScript.
- `js/main.js`: variables, funciones y lógica del simulador.

## Tecnologías

- HTML5
- JavaScript
